Aurora 3.0 keeps the original theme's static-first publishing model while moving routing, content collections, SEO, taxonomy, RSS, sitemap, and Pagefind indexing to Astro build time.

The single Markdown pipeline supports CommonMark, GFM, Aurora containers, Shiki syntax highlighting, safe raw HTML media, and build-time KaTeX math. Focused Vue islands provide search, theme persistence, mobile navigation, lightbox, code copy, comments, and Dia without turning the site into a client-rendered application.

The public Demo uses Aurora Demo as an explicit showcase identity. Its profile, comments, links, counters, and started date are deterministic fixture data and are excluded from ordinary builds. See the [repository](https://github.com/yanpuzhen/astro-theme-aurora), [documentation](https://yanpuzhen.github.io/astro-theme-aurora/), and [license](https://github.com/yanpuzhen/astro-theme-aurora/blob/main/LICENSE) for the current implementation and attribution.
