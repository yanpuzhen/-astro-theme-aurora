# 社交链接

作者 frontmatter 为迁移兼容保留了 `socials` record：

```yaml
author:
  name: Aurora Team
  link: https://example.com/team
  socials:
    github: https://github.com/yanpuzhen
```

当前 Aurora 3 RC 会在文章 Meta 中渲染作者 identity 和 link，但没有完整的 upstream 风格社交链接面板或统计系统。不要假定旧 Hexo social 配置仍然运行。

这里明确记录边界，不为文档偷偷扩大功能范围。可见链接请使用普通菜单项或页面内容。
