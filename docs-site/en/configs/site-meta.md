# Site Meta

Every generated page receives build-time metadata from `BaseLayout.astro`.

- Canonical URLs use `ASTRO_SITE` plus `ASTRO_BASE` and the route resolver.
- OpenGraph includes title, type, URL, locale, site name, description, and cover when available.
- Twitter card metadata is `summary` or `summary_large_image` depending on the cover.
- Article pages include author, published/modified times, and tags.
- JSON-LD emits `WebSite` for ordinary pages and `BlogPosting` for posts.
- `rss.xml`, `sitemap.xml`, and `robots.txt` are generated by Astro routes.

For a project site, `ASTRO_SITE=https://yanpuzhen.github.io` and `ASTRO_BASE=/astro-theme-aurora/` produce canonical URLs below the project path. The Demo uses the additional `/demo/` segment. Keep both values aligned with the real public deployment; a listening dev server cannot validate canonical URL correctness.

The Demo's site identity is intentionally `Aurora Demo`. Its profile, recent comments, friend links, counters, and started date are showcase fixtures. Ordinary builds hide those values unless the corresponding site configuration is supplied.
