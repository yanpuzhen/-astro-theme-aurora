# General Configuration

Aurora 3.0 reads the public site origin and deployment prefix from `ASTRO_SITE` and `ASTRO_BASE`. The static config defaults are in `src/lib/config.ts`.

| Setting | Source | Meaning |
| --- | --- | --- |
| `site` | `ASTRO_SITE` | Public origin used for canonical URLs, OpenGraph, RSS, sitemap, and JSON-LD. |
| `base` | `ASTRO_BASE` | Path prefix for a project-site or nested deployment. Use a trailing slash. |
| title | `config.site.title` | Site and browser title seed; currently `Aurora 3.0`. |
| description | `config.site.description` | Default description for the site shell. |
| author | `config.site.author` | Footer author and default author fallback. |
| locale | `PUBLIC_AURORA_LOCALE` | `en` or `zh-CN` for static labels. |
| feature section | `config.theme.feature` | Enables the current featured-post selection logic. |

Example:

```sh
ASTRO_SITE=https://yanpuzhen.github.io \
ASTRO_BASE=/astro-theme-aurora/demo/ \
PUBLIC_AURORA_LOCALE=en \
pnpm build
```

Pagination is generated by the current route implementation: the home selection uses 12 items in feature mode and 13 in non-feature mode; archives use 12. These are implementation constants in Aurora 3 RC, not environment variables.

The Demo uses a separate build invocation and does not require OAuth or a comment provider.
