# ADR 006: Static labels are translated at build time

- **Status:** ACCEPTED
- **Date:** 2026-09-19

## Decision

The `en`, `zh-CN`, and `zh-TW` dictionaries are loaded at build time. Astro renders static labels and SEO language metadata. A small island may handle locale preference/navigation; the entire site is never hydrated only for translation.

## Context

The legacy route guard changes vue-i18n and document titles at runtime, even for static content.

## Consequences

Locale URLs/configuration must be decided before rendering. Interactive labels need an explicit island dictionary and fallback behavior.
